Paso 0: Ejecutar (Opcional)

Bash
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
Set-ExecutionPolicy Unrestricted -Scope Process

----------------------------------------------------------------------------------------------
Paso 1: Crear el entorno virtual
Abre la terminal en la carpeta donde guardarás tu proyecto y ejecuta:

Bash:
python -m venv nombre_entorno

----------------------------------------------------------------------------------------------
Paso 2: Activar el entorno virtual
Ejecuta el script de activación según tu sistema operativo:

En PowerShell:
.\nombre_entorno\Scripts\activate

En CMD:
nombre_entorno\Scripts\activate.bat

En Linux / macOS / Git Bash:
source nombre_entorno/bin/activate

----------------------------------------------------------------------------------------------
Paso 3: Instalar Django
Con el entorno activo, instala el marco de trabajo mediante pip:

Bash:
pip install django
o
python -m pip install django

----------------------------------------------------------------------------------------------
Paso 4: Crear el proyecto Django
Genera la estructura inicial de archivos de Django:

Bash:
django-admin startproject nombre_proyecto

----------------------------------------------------------------------------------------------
Paso 5: Ingresar a la carpeta del proyecto (Si no usaste el punto en el Paso 4)

Bash:
cd nombre_proyecto

----------------------------------------------------------------------------------------------
Paso 5.1: Se generan las aplicaciones segun corresponda:

Bash:
python manage.py startapp nombre_app 

----------------------------------------------------------------------------------------------

Paso 5.2: Se instala la libreria para manejo de base de datos:

Bash:
pip install psycopg2

EXTRAS
• Para ver la lista de librerias instaladas:

Bash:
pip lista

• Para generar un archivo con las librerias en formato .txt:

bash:
pip freeze > "nombre_archivo.txt"

• Para instalar dependecias, librerias o package:

Bash:
pip install Django psycopg PyGreSQL pytest nombre_de_paquetes_o_librerias

• Para ver la lista completa de comandos:

pip -help

• generar los modelos para la base de datos:

python manage.py makemigrations

• Activar base de datos:

Bash:
python manage.py migrate

• Para crear super Usuario

Bash:
python manage.py createsuperuser

• Para resolver problemas con el interprete de python:

Selecciona el intérprete correcto:
Presiona Ctrl + Shift + P (o Cmd + Shift + P en Mac) para abrir la paleta de comandos en VS Code.
Escribe y selecciona Python: Select Interpreter
Selecciona la version de Pyton que este contenida en el proyecto
